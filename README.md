# Library Catalog API

RESTful API сервис для управления каталогом библиотеки. Проект построен на современной асинхронной архитектуре с использованием FastAPI и PostgreSQL, а также включает автоматическое обогащение данных о книгах через интеграцию с внешним сервисом Open Library.

## 🚀 Ключевые особенности

- **Полная асинхронность**: Обработка HTTP-запросов и работа с базой данных реализованы полностью в асинхронном режиме без блокировок Event Loop.
- **Отказоустойчивость (Resilience)**: При недоступности сторонних сервисов приложение не падает, а продолжает работу и сохраняет базовые данные.
- **Безопасность**: Использование UUID вместо инкрементальных ID для защиты данных от перебора.
- **База данных**: PostgreSQL в связке с SQLAlchemy 2.0 (asyncpg) и системой миграций Alembic.

## 🛠 Стек технологий

- **Язык**: Python 3.12
- **Фреймворк**: FastAPI
- **База данных**: PostgreSQL
- **ORM & Миграции**: SQLAlchemy, Alembic
- **HTTP Клиент**: httpx
- **Контейнеризация**: Docker, Docker Compose
